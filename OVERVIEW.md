Finance.py uses streamlit to run to python program locally.
There are options that allow you to choose what coin or currency that you want to study and a trend map of the value of the coin/currency over time.

Projection.py
This has a camera and a projection skill and uses unit vectors to project onto your screen.
So that more educated decisions can be made.

Read both README.md and SETUP.md in this branch to get more steps on what to do.
