The goal of this project is to educate people regarding the nature and volatility of the stock market.
This was chosen upon observation of how the stock market was portrayed as easy on social media platforms.
For this cause. There was a reason to show them how it actually was realistically. Using game like observation systems. Projection.py is going to be great for VR users to game through.


Projection.py
This has a camera and a projection skill and uses unit vectors to project higher dimensional data onto your screen.
So that more educated decisions can be made. It uses color to represent a moving average. Red being low and green being high.
Finance.py uses streamlit to run to python program locally, it does not matter projection.py does.
There are options that allow you to choose what coin or currency that you want to study and a trend map of the value of the coin/currency over time.
This was the base project on just education of people regarding the stock market. It clustered the price of shares of major tech brands and projected them well on a graph.

Read both README.md and SETUP.md in this branch to get more steps on what to do.
