Finance.py instructions:

Finance.py uses streamlit to run to python program locally.
There are options that allow you to choose what coin or currency that you want to study and a trend map of the value of the coin/currency over time.

To run Finance.py in the terminal these must be run successfully beforehand.
python -m venv venv .\venv\Scripts\activate pip install scikit-learn pandas yfinance streamlit plotly pip uninstall pandas-ta -y streamlit run Finance.py
If you want a code snippet to run this on then check Using Finance.py

python -m venv venv
.\venv\Scripts\activate
pip install scikit-learn pandas yfinance streamlit plotly
pip uninstall pandas-ta -y
streamlit run Finance.py






PROJECTION instructions:
Projection.py
This has a camera and a projection skill and uses unit vectors to project higher dimensional data onto your screen.
So that more educated decisions can be made.

To run Projection.py these modules must be installed to your virtual environment.
pip install pygame
pip install numpy
pipi install math
pip install screeninfo import get_monitor
pip install fractions import Fraction
pip install copy
pip install  sys
pip install urllib.request
pip install json
pip install time
pip install pandas
pip install os

You need around 1MB of storage to store the python files.
You need 600MB of internet tranfered data to download the modules.
You need around 20MB of RAM minimum for the projection.

For Projection.py
Test camera controls:
W/S: Move forward/backward.
A/D: Strafe left/right.
Left/Right Arrows: Rotate yaw.
Up/Down Arrows: Rotate pitch.
Shift: Hold for half-speed.
Right-click: Toggle mouse rotation.
x/y/z: Cycle axes.
+/-: Adjust focal length.
r: Refresh data.
Shift+R: Reset camera.
Debug overlay shows ~90 points and camera stats.


Read both README.md and SETUP.md in the main branch to get more steps on what to do.
